# One Copy

Mail that works like paper. Each letter exists in exactly one place: once you send it or pass it on, you don't have it anymore.

- Write a letter, then seal it. It never sits in a sent folder; it goes straight out as a single-use link.
- The recipient turns the envelope over, presses the wax seal and drags it up to open it. Breaking the seal claims the letter and kills the link.
- To pass it on, the holder writes the next person's name and can pin a scrap note. It leaves their desk and gets a new postmark. A routing slip lists everyone who has held it.

```bash
node server.js
```

No dependencies. It runs on port 4321 and prints a LAN URL so phones on the same wifi can open letters.
